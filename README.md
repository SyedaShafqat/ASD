# ASD Knowledge Graph - Core Datasets

This repository contains the primary datasets used to construct the Autism Spectrum Disorder (ASD) Knowledge Graph.

## Main Files

### 1. ASD-MyAutismFullDrug
Contains ASD-associated drugs and their corresponding target genes/proteins collected from DrugBank and related biomedical resources.

### 2. ASD-MyAutismDrugSideEffects
Contains side effects associated with ASD-related drugs, integrated to support drug safety and adverse effect analysis.

### 3. ASD-GENES_WITH_HPO_MERGED
Contains ASD-associated genes merged with Human Phenotype Ontology (HPO) annotations, linking genes to autism-related phenotypic features.

## Purpose

These datasets serve as the core input for constructing the ASD Knowledge Graph by integrating drugs, genes, phenotypes, and drug side effects into a unified Neo4j graph for biomedical knowledge discovery and querying.
